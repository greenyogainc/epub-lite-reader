# Store listing copy — EPUB Lite Reader 1.0.6

Description, Product features, and Search terms are unchanged from 1.0.5.
See `../store-listing.md` for the full per-language listing copy.

Only the "What's new" section is updated for 1.0.6.

---

## What's new in 1.0.6 (en-US)

```
• Security: scripts are now removed from every book file that could open as a page — including SVG images and files with a mislabeled type — not just from chapters
• Robustness: damaged or hostile EPUB files can no longer make opening a book hang, and oversized chapters are skipped instead of being extracted
• Reliability: a damaged saved-state file can no longer stop a book from opening or the app from starting
• Fixed a resource leak when the About window is closed while the Contact support page is still loading
```

## What's new in 1.0.6 (zh-Hans)

```
• 安全性：现在会从所有可能作为页面打开的书籍文件（包括 SVG 图像和类型声明错误的文件）中移除脚本，而不仅限于章节
• 稳健性：损坏或恶意的 EPUB 文件不会再导致打开书籍时卡住，过大的章节将被跳过而不会被解压
• 可靠性：损坏的已保存状态文件不再会导致书籍无法打开或应用无法启动
• 修复了在“联系支持”页面仍在加载时关闭“关于 EPUB Lite Reader”窗口导致的资源泄漏
```

## What's new in 1.0.6 (zh-Hant)

```

• 穩健性：損毀或惡意的 EPUB 檔案不會再導致開啟書籍時停滯，過大的章節將被略過而不會被解壓縮
• 可靠性：損毀的已儲存狀態檔案不再會導致書籍無法開啟或應用程式無法啟動
• 修正在「聯絡支援」頁面仍在載入時關閉「關於 EPUB Lite Reader」視窗所造成的資源洩漏
```

## What's new in 1.0.6 (ru)

```
• Безопасность: скрипты теперь удаляются из всех файлов книги, которые могут открыться как страница (включая изображения SVG и файлы с неверно указанным типом), а не только из глав

• Стабильность: повреждённый файл сохранённого состояния больше не мешает открыть книгу или запустить приложение
• Исправлена утечка ресурсов при закрытии окна «О программе EPUB Lite Reader» во время загрузки страницы «Связаться со службой поддержки»
```
